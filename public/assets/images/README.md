# HelloBotz Images — Upload Guide

Place your images here. Recommended sizes:

| File | Size | Usage |
|------|------|-------|
| logo.png | 280×72 | Header logo |
| logo-footer.png | 280×72 | Footer logo |
| favicon-32x32.png | 32×32 | Browser tab |
| apple-touch-icon.png | 180×180 | iOS home screen |
| og-image.png | 1200×630 | Social share |
| hero-dashboard.png | 1200×750 | Homepage hero |
| brands/brand-1.png … brand-6.png | 160×48 each | Trusted logos |

All pages use relative paths via `$basePath`, so images work from root and subfolders.
Replace files with the same names — no code changes needed.
